# ArchiveOS 공개 서비스 안내

ArchiveOS는 Archive 생태계의 상태, 처리 흐름, 승인 대기, 재무 균형을 한 화면에서 읽기 전용으로 보여주는 운영 콘솔입니다.

## 공개 화면에서 확인할 수 있는 범위

- Archive-Market, Archive-Nexus, Archive-Logistics, Archive-Ledger의 현재 서비스 상태
- 최근 합성 런타임 이벤트와 서비스 간 처리 흐름
- 승인 및 처리 대기 건수의 요약
- 합성 데이터 기반 서비스별 매출, 비용, 영업이익과 목표 범위
- 공개가 승인된 운영 지식과 정책 설명

## 지식 답변의 한계

문서 기반 답변은 승인된 공개 문서의 내용을 설명하며 실제 서비스 상태를 점검했다는 의미가 아닙니다. 현재 상태 확인이 필요한 질문은 별도의 실시간 점검 계획을 만든 뒤 사용자가 명시적으로 승인해야 합니다.

ArchiveOS는 근거가 부족한 경우 확인할 수 없는 이유를 표시하고, 문서 근거와 실시간 증거를 구분합니다.
