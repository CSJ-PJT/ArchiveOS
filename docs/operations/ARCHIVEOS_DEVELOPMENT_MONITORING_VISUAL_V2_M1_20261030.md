# 2026-10-30 사용자 지시 — ArchiveOS 기존 '개발 관제' Visual V2 M1 전면 개편

**적용 대상: ArchiveOS / 기존 개발 관제 메뉴 하나.** 다른 게임 개발자·DeepStake Unity MAIN 작업에 명령하거나 신규 세션을 만들지 않는다.

## 최상위 경계
- **메인 ArchiveOS 대시보드, 채용공고, 메일, 일정, 일반 운영/재무/서비스, 인증·기존 API·DB는 변경하지 않는다.** 사용자는 이미 2026-10-30 OCI 운영판에서 게임 정보를 일반 대시보드에서 제거하고 전용 개발 관제에 한정했다고 보고했다. 먼저 이 상태를 실사·보존하고 되돌리지 않는다.
- 구형 GitHub main(2026-07-31) 또는 PR #17을 OCI 최신 운영 소스 전체에 덮어씌우지 않는다. **현재 OCI에 올라간 소스/실제 컴포넌트/배포 락·버전**부터 확인한다.
- 이 문서는 화면·데이터·검증 인수인계이며 **게임 완성률 추정치나 CodeX 자체 PASS를 출시 승인으로 격상하지 않는다.** 안심동행 프로젝트 제외.
- **첫 목표는 Visual V2 첫 생활권(M1)의 시각 품질 수용 100%**, 21개 이상 전체 구역 완성/전체 게임 출시 100%가 아니다.

## 새로운 화면 정보 구조

### 0. 헤더 / 4 KPI / 첫 화면에서 차단 확인
제목 `DeepStake | Visual V2`, 부제 `Steam Windows PC / M1 첫 생활권 시각 수용`.
4 KPI:
1. `M1 수용 관문`: 근거가 있는 승인 PASS 개수 / 8 (NOT_RUN, BLOCKED, FAIL를 완료로 넣지 않음). "M1 관문 수용률"이지 전체 게임 완료율이 아님.
2. `최신 Windows Native`: 실제 build receipt의 버전/sourceSHA/buildSHA/PID/exit/PASS 범위와 시각; 자체/독립 QA 구분.
3. `구형 시각 구조물`: 새 Visual V2 장면의 legacy building/road/factory-call active count = 0 요구; 원본 근거 없으면 미검증, "0"으로 추측 금지.
4. `최우선 차단`: 콘셉트 수용·GPU strict·실제 물리 입력·출시 게이트 중 위험 하나와 증거/담당/종료조건.
상단에는 마지막 원본 실행 시각, 수집 시각, 데이터 신선도(신선/지연/소실)와 빌드 동일성 배지 표시.

### 1. Visual V2 M1 수용 관문 (8개)
각 관문에 PASS / FAIL / BLOCKED / NOT_RUN / SELF_VERIFIED / INDEPENDENT_VERIFIED / USER_APPROVED 등 **서로 다른 의미**를 보이도록 UI 배지/표현 분리한다.
1. Legacy 시각 표현 경로 제거 (동일 source-matched Windows 실행에서 신규 장면 구형 시각 인스턴스·factory call 0)
2. 신규 시작 골목 실제 Windows 화면 (좁은 골목·실제 이동/충돌/출입구)
3. 슈퍼 전면 실제 Windows 화면 (개별 아트·실제 구매 상호작용)
4. 일반 주거·마당 실제 Windows 화면 (서로 다른 건물 유형·가림/정렬)
5. 카메라/지면/건물·차량 가림/그림자/렌더 안전 정합성
6. 콘셉트 수준의 아트·밀도·상점/간판/재질/주민 비율 및 출처 승인
7. 같은 Visual V2 Windows 빌드의 생활 루프/입력·GPU·성능 필수 회귀 (FAIL은 전체 M1 PASS 차단; 합성 입력/물리 입력 구분)
8. 사용자의 **실제 게임 화면** 시각 승인
누적 PASS만 M1 100% 기준에 반영; 자동 임의 승인/이미지 생성시안 PASS 금지.

### 2. 실화면 비교 허브 (핵심, 카드/캐러셀)
시작 골목·슈퍼·주거 마당 3탭 × `승인된 원본 콘셉트` | `구형 v309` | `실제 신규 Visual V2 Windows 캡처`. 가능하면 좌표·카메라·해상도를 표시하고, V2 카메라 구도가 달라졌으면 "카메라 변경"으로 분명하게 설명. 생성된 목표 이미지는 별도 `컨셉 시안`이며 실제 Native 화면으로 표시 금지.
시각 항목: 골목 폭/건물 비율/유형 다양성/간판·상점/주민 밀도/재질·조명/카메라/가림. 비교 항목별 차이/검토자/사진·영상 sha/승인 이력. 이미지 없으면 플레이스홀더와 '실제 Windows 캡처 없음' 명시.

### 3. 게임 아트/장면 파이프라인

## 진척률 규칙
- 과거 24% = 72개 원장 총수/배점 미복구된 역사적 값, 현재 전체 완료율 아님.
- 과거 26.4% = v271 중심 9영역 수동 가중 추정으로 수학적 계산만 재현 가능, 현행 Visual V2 대표 지표 퇴역.
- 과거 56/100 = 첫 마을 *과거* 자체 증거 점수, 현재 56%가 아님.
- 신규 15.9% = 모델 가정에 따른 낮은 신뢰의 임시 시나리오, 서비스 대표 값/증감 추세에서 **사용 금지**.
- **M1 수용률 = 근거가 있고 정해진 승인 절차를 통과한 게이트 수/8**. 영역별 데이터가 없으면 0/8으로 조작하지 말고 확인되지 않은 관문 수를 명시하며 0 PASS/8은 단지 확인한 PASS가 없다는 뜻으로 설명.
- 전체 게임 100% 완료율은 수용 가능한 원본 범위/배점이 확정되기 전 `평가 기준 재정립 중`으로 별도 보관. 하단 접힌 `역사적 기준선`에서 24%,26.4%,56/100의 근거·한계 설명.
